____**Library Management System**____

**C Programming | Data Structures | Singly Linked List | File Handling**

 Project Description

The Library Management System is a console-based application developed using C programming to organize and manage library book records.
The project focuses on implementing fundamental data structures and core programming concepts through a practical application.
A Singly Linked List is used for dynamic memory allocation and efficient record management, while file handling provides data storage and retrieval.
The application follows a modular programming approach, with individual functionalities organized into separate header files to improve code readability, maintainability, and reusability.

Functional Modules

 Module and Description 

 Add Book - Inserts new book records into the linked list. 
 Display Books - Displays the available book information. 
 Search Book - Searches for a specific book using its ID. 
 Update Book - Modifies existing book information. 
 Remove Book - Deletes selected book records. 
 Save Records - Stores book information in a file. 
 Read Records - Retrieves previously stored records. 
 Main Menu - Provides menu-driven access to all operations.

 Data Structure

 Singly Linked List

The application uses a singly linked list to maintain book records dynamically.

Each node consists of:

- Book ID
- Book Name
- Author Name
- Pointer to the next node

This implementation provides dynamic record management without requiring a predefined storage capacity.
